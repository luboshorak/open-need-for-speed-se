Place the files from your legally owned The Need for Speed Special Edition CD here.
Expected example files, relative to this CD_Data directory:
  FRONTEND\ART\CONTROL\CENTRAL.QFS
  SIMDATA\MISC\AL1.TRI
  SIMDATA\CARFAMS\MRX7.CFM
  SIMDATA\SOUNDBNK\RX7_SW.BNK
No copyrighted game data is included with OpenNFS1.
The folder used at runtime is alongside OpenNFS1.exe; set cdDataPath in gameconfig.json
or pass --data <path> for a different location.
